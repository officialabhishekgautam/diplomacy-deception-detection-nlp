# diplomacy-deception-detection-nlp
Multi-model NLP pipeline for detecting deception in Diplomacy game messages. Implements domain-adaptive RoBERTa, BiLSTM+CRF, and LightGBM+SentenceBERT approaches with rich metadata features. Achieves 91.24% accuracy and 0.7976 ROC-AUC on QANTA Diplomacy dataset. Comparative analysis of transformer vs traditional ML methods.
